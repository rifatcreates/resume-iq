# ResumeIQ — AI-Powered Resume Analyzer
An intelligent web app that analyzes your resume using Google Gemini AI. Upload your PDF resume and get instant feedback on strengths, improvements, ATS compatibility, performance metrics, and more.

## Live Demo
🔗 [resumeiq-xxx.vercel.app](https://resumeiq-xxx.vercel.app)

## Features
- 🔐 Email/password authentication
- 📄 PDF resume upload with drag & drop
- 🤖 AI-powered resume analysis using Google Gemini
- 🏆 Overall score with performance metrics
- ✅ ATS compatibility check & optimization tips
- 💡 Personalized action items & pro tips
- 🔑 Recommended keywords for your industry
- 📊 Detailed breakdown of strengths & improvements
- 📁 Save and view past analysis history
- 📱 Fully responsive

## Tech Stack
- React + TypeScript
- Tailwind CSS + Shadcn/ui
- Google Gemini API
- Supabase (Auth + Database + Storage)
- TanStack Query
- React Router v6
- Vercel (Deployment)
